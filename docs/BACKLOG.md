# Отложенные задачи

- Семьи, возраст, характер, навыки и отношения жителей.
- Торговые маршруты, новые деревни, культуры, дипломатия, конфликты и королевства.
- Продвинутая репутация, вступление игрока в поселение, жильё и влияние на приоритеты.
- Прогресс при закрытой игре. Сначала подтвердить модель серверной сессии.
- Интеграция с системами защиты участков после проверки реального API и политики владельца мира.
