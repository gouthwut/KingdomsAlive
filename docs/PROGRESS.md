# Прогресс

## 2026-11-09 · Подготовка GitHub и релизов

- Целевой репозиторий `gouthwut/KingdomsAlive`. GitHub CLI авторизован, `main` содержит два исходных коммита, remotes и тегов нет. Публикация исходников, настройка репозитория и отправка релизного тега ожидают разрешения.
- Добавлены англоязычные README и CONTRIBUTING, формы для багов и предложений, правила исключения локальных файлов и [инструкция по релизам](RELEASING.md). LICENSE ожидает согласования.
- Gitleaks проверил оба коммита и 29 файлов кандидата на публикацию. Секретов, бинарных файлов и машинных путей не обнаружено. Метаданные используют адреса GitHub noreply. Сохранения, журналы и тестовые артефакты исключены из набора публикации.
- Подготовлен workflow Windows с закреплёнными ревизиями упаковщика и проверяющего инструмента Horizon. Локально на Rust 1.99.0 прошли проверки форматирования ядра и хука, Clippy и четыре теста. Релиз требует разрешающей переменной репозитория, совпадения тега с версией манифеста, LICENSE и одобрения защищённого окружения.
- Локально собран официальный валидатор из закреплённой ревизии. Два прогона упаковки из подготовленного дерева дали один SHA-256, валидатор в обоих случаях вернул `ok: true`. В архиве только метаданные, TOML и Rust-хук. Actionlint прошёл, проверка тега отклоняет сборку без LICENSE. Прогон на GitHub-hosted runner ещё предстоит.
- Сборка пакета отделена от компиляции лаунчером и прогона в мире. M0 остаётся завершённым. Критерии M1 и игровой код сохранены.

## 2026-11-09 · M1 начат

- `src/settlement.rs` хранит идентификатор, имя, территорию, UUID жителей, жильё и ресурсы. Приоритет пересчитывается из фактических полей модели.
- `src/persistence.rs` сохраняет снимок схемы 1 и отказывается заменять повреждённый файл или файл более новой схемы.
- `cargo test --locked --offline` прошёл 4 теста, включая повторное чтение и замену снимка с полным диапазоном UUID. `cargo fmt --all --check` и `cargo clippy --locked --offline --all-targets -- -D warnings` прошли.
- Регистрация существующей деревни, вызов ядра на сервере и повторное открытие сохранения из игры остаются критериями M1.
