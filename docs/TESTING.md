# Проверки

## M0

1. Выполни `rustfmt --check mixins/kingdoms_alive/server_start_smoke.rs`.
2. Собери мод лаунчером по [README](../README.md). В `%APPDATA%/horizon-launcher/native/build.log` ищи успешное применение одного mixin и завершение Cargo.
3. Открой `KA-M0-Smoke` в профиле `kingdoms-alive-m0`. Проверь, что загружен мир и в журнале есть `[kingdoms_alive] M0 server_about_to_start dedicated=false`. Журнал профиля находится в `%APPDATA%/horizon/instances/kingdoms-alive-m0/logs/latest.log`. При автоматизированном запуске через `horizon-ctl` также проверь журнал рядом с адресом управления.
4. Вместо ручного запуска можно выполнить `python tools/smoke_m0.py`. Скрипт требует включённого Horizon MCP и тестового профиля со сборкой. Он ждёт появления игрока и загрузки чанков, ищет маркер в журнале и сохраняет `result.json` и `world.png` в `target/m0-smoke/`. По окончании скрипт закрывает игру с сохранением. Для независимой проверки пакета используй `cargo horizon-mod check target/kingdoms_alive-0.1.0.hnmod --json`.

## Игровые этапы

- Модульные тесты проверяют границы остатков, резервирование, возврат груза, приоритеты и повторную сдачу заказа.
- Интеграционные тесты проверяют полный оборот ресурса, возобновление строительства, сохранение и миграции. Для ошибок записи проверяй предыдущий снимок и повтор операции.
- В игре наблюдай живых NPC, блоки, инвентарь и реальное сохранение с перезапуском. Для конфликтов измени блок между назначением задания и применением, затем сравни состояние и остатки.
- В M6 измеряй для 1, 5, 10 и 25 поселений длительность серверных тиков (p50, p95, p99), память, время записи, FPS и глубину очередей. Используй один мир и одинаковые настройки, запиши длительность и параметры прогонов.
