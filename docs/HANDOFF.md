## Следующие действия

M2 ещё не завершён. Нужны общий реестр сундуков, ограниченная запись и сверка незавершённых переносов. В закреплённой ревизии Horizon нет атомарной сохраняемой операции между блоком, экипировкой жителя и сундуком: текущий пилот fail-closed, но авария между раздельными записями может потерять груз. Сначала нужен журналированный идемпотентный перенос и тесты отказов, затем лесоруб: добыча только через `native_machine_destroy_block(..., collect = true)` с сохранением фактического лута.
