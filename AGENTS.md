# Kingdoms Alive

Нативный мод на Rust для Horizon (Minecraft: Java Edition 26.3). Деревни самостоятельно добывают, расходуют и строят из ресурсов Minecraft.

В новом чате прочитай [HANDOFF](docs/HANDOFF.md), затем [PROGRESS](docs/PROGRESS.md). Дальше открывай только относящиеся к задаче документы. [ROADMAP](docs/ROADMAP.md) задаёт критерии этапов, [HORIZON_API](docs/HORIZON_API.md) фиксирует проверенные границы платформы.

- Переходи к следующему этапу только после выполнения критерия текущего.
- Сверяй каждый вызов Horizon с каталогом и исходником выбранной ревизии. Храни правила симуляции отдельно от адаптеров Horizon.
- Изменяй только одобренные зоны поселения и только после проверки загруженности и ожидаемого состояния блока. При конфликте отложи действие.
- Используй блоки, предметы и сущности Minecraft. Новые визуальные ресурсы и смена платформы требуют согласования.
- Проверяй мод на отдельном профиле и тестовом мире. Разделяй сборку, загрузку в игре и функциональные проверки. Не публикуй сборки без согласования.
- После существенной работы обновляй PROGRESS и HANDOFF. Решения с долгосрочными последствиями записывай в DECISIONS.
